## 📌 About The Project

This project contains four practical Python tasks designed to build a foundation in Python programming.

The main objective is to understand how Python handles decision-making, manages data using dictionaries, and performs basic file operations.

## 🎯 Learning Objectives

Through this assignment, I practiced:

- ✅ Conditional Statements (`if`, `elif`, `else`)
- ✅ Dictionary Operations (Add, Update, Access)
- ✅ Loops (`while` and `for`)
- ✅ User Input Handling
- ✅ File Handling (`open()`, `read()`, `write()`, `close()`)
- ✅ Reading and Writing Text Files

## 📝 Assignment Tasks

### 1️⃣ Grade Checker

**Objective:** Take marks as input and display the corresponding grade.

| Marks | Grade |
|---|---|
| 90 and above | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| Below 60 | F |

**Concepts Used:**
- User input
- Conditional statements
- Input validation

### 2️⃣ Student Grades

**Objective:** Create a student grade management program using a Python dictionary.

**Features:**
- ➕ Add a new student and grade
- 🔄 Update an existing student's grade
- 📋 Display all student records
- 🚪 Exit the program

**Concepts Used:**
- Dictionaries
- While loop
- If-else statements
- Dictionary methods

### 3️⃣ Write to a File

**Objective:** Create a text file and write student information into it.

**Concepts Used:**
- `open()`
- Write mode (`"w"`)
- `write()`
- `close()`

### 4️⃣ Read from a File

**Objective:** Read the contents of an existing text file and display them.

**Concepts Used:**
- Read mode (`"r"`)
- `read()`
- File handling

## 🚀 How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/YOUR_USERNAME/Python-and-Bash-Assignment.git
```

**Step 2:** Navigate to the project directory.

```bash
cd Python-and-Bash-Assignment
```

**Step 3:** Run any task.

```bash
python Task_1_Grade_Checker/grade_checker.py
```

```bash
python Task_2_Student_Grades/student_grades.py
```

```bash
python Task_3_Write_File/write_file.py
```

```bash
python Task_4_Read_File/read_file.py
```

**Note:** Run the commands from the main project directory so that the relative file paths work correctly.
